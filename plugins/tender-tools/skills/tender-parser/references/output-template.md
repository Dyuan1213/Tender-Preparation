# 输出模板

---

## 使用说明

- 所有 `[...]` 占位符须替换为实际内容
- "文件未载明"用于未在文件中找到的信息
- ⚠️ 用于存在矛盾表述或特别需要关注的地方
- 速览表格控制在 5-7 行，突出最关键信息
- 投标准备建议部分需结合文件实际情况撰写，不要给通用建议
