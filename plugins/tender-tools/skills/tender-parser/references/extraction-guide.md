## 文件类型识别

中文招标文件通常属于以下类型，识别后可有针对性地定位关键内容：

| 类型 | 典型标志词 | 评分结构特点 |
|------|-----------|-------------|
| 政府采购（货物/服务） | "采购文件"、"采购编号"、"财政"、"政府采购" | 价格分通常30%，评分表格化 |
| 工程建设招标 | "施工招标"、"EPC"、"工程量清单" | 技术标/商务标分开，价格分权重高 |
| 竞争性磋商/谈判 | "磋商文件"、"响应文件" | 流程与招标有差异，注意区分 |
| 框架协议采购 | "框架协议"、"入围" | 可能无固定合同金额 |

## 各维度提取规则

### 时间节点

- 时间必须精确到"年月日 时:分"，不接受模糊表述
- 注意区分"投标截止时间"和"开标时间"（有时相同，有时有间隔）
- 投标有效期：找"投标截止日后XX天"或"开标后XX天"等表述
- 若文件仅标注"以公告为准"，提示用户需关注官方公告

### 资质要求（重点）

**分层识别资质要求的强制性：**

- **"须具备"、"应具有"、"必须提供"** → 强制性，标🔴
- **"优先考虑"、"有XX证书的优先"** → 加分项，标🟡
- **"鼓励"** → 非强制，标🟢

**业绩要求的完整要素：**
提取时需包含：① 业绩类型（合同名称/项目类型），② 数量要求（"不少于X个"），③ 规模要求（合同金额、面积、规模等），④ 时间范围（"近X年内"的起算点）

**禁止投标情形：** 通常在"投标人资格要求"或"投标须知"中，注意搜索"不得参加"、"禁止"、"列入失信"等关键词

### 评分标准

**提取完整评分表：**
不要仅提取分值小计，要提取每个子项的评分标准描述，因为"满足要求得X分"和"每增加一项得X分"的评分逻辑完全不同。

**计算价格分的公式：**
常见公式有两种，需准确识别：
- 低价优先法：`价格分 = 最低价/投标价 × 价格权重分`
- 基准价法：`价格分 = (1 - |投标价 - 基准价|/基准价) × 价格权重分`

### 实质性响应条款

**定位技巧：**
搜索"实质性响应"、"不满足则废标"、"负偏离"、"必须响应"等关键词

**常见废标情形（需全部列出）：**
- 未按要求密封
- 未缴纳投标保证金
- 投标文件未加盖公章
- 超出最高限价
- 未响应某技术参数
- 提交虚假材料

## 表格处理

招标文件中常见表格类型及处理方法：

### 评分表格
将表格转换为有层级的列表：
```
技术分（60分）
  ├─ 方案可行性（20分）：优秀20分、良好15分、一般10分
  ├─ 团队配置（15分）：项目经理证书每项3分，最高15分
  └─ 售后服务（25分）：...
```

### 资质要求表格
转换为"要求项：具体内容"格式，每行独立列出

### 技术参数偏离表
提取"★"或"▲"标注的关键参数（这类参数往往是实质性要求），普通参数可概括说明

## 常见陷阱

1. **"甲方"误读**：注意分清"采购人"和"代理机构"，有时文件中采购人和代理机构都叫"甲方"，需通过上下文区分

2. **多个有效期**：注意区分"投标有效期"（保持投标效力的期限）和"合同有效期"（项目执行期限），不要混淆

3. **证书年检问题**：有些文件要求证书"在有效期内"，提示用户核查自身证书有效期

4. **业绩的时间起算**：一般招标文件写"近3年"，时间起算通常以开标日期往前推，但部分文件以"发布公告之日"起算，需仔细核查

5. **联合体限制**：部分文件写"不允许联合体投标"，但这通常出现在附则中，容易被忽略

6. **最高限价 vs 预算**：预算是采购方的内部参考，最高限价是对投标方有约束力的上限，超过即废标

## 特殊场景处理

### 文件超长（超过100页）
- 优先阅读目录，定位各章节
- 重点阅读：第一章（总则/投标须知）、资格要求章节、评分标准章节、合同条款章节
- 技术规格/技术参数章节可概括性描述，不需逐条列出

### 文件包含多个标段/包
- 按标段分别提取资质要求和技术要求
- 在报告中用"标段一/标段二"等清晰分组
- 注意说明是否允许同时投多个标段

### 补遗文件/答疑纪要
- 如用户同时提供了答疑纪要，其内容对原招标文件具有修改效力
- 提取时以答疑纪要的内容为准，并注明"（已按答疑纪要更新）"
