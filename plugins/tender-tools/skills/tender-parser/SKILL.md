# 招标文件解析 Skill

## 目标

读取招标文件（PDF 或 Word），提取全部关键信息，输出一份结构清晰、要点突出的 Markdown 摘要报告，帮助投标方快速判断项目情况、资格符合性、以及投标准备事项。

## 工作流程

### 第一步：读取文件

**优先方案（无需Bash权限）：**
- 如果用户提供了文件路径，先尝试用 Read 工具直接读取该文件
- 如文件已被预先提取为 .txt 文件，直接 Read 该文本文件（分批读取，每次 limit 400 行，通过 offset 翻页）
- DOCX/PDF 内容较长时，分多次 Read 完整读取所有内容，不要遗漏表格部分

**备选方案（需要Bash权限）：**
- DOCX：运行 `python "${CLAUDE_PLUGIN_ROOT}/skills/tender-parser/scripts/read_docx.py" <path> --output extracted.txt`，再 Read 输出文件
- PDF：用 `pdfplumber` 或 `pdfminer` 提取文本

> 路径说明：`${CLAUDE_PLUGIN_ROOT}` 会被 Claude Code 自动替换为本插件的实际安装路径；若本 skill 作为独立 skill（非插件）使用，则改用本 skill 目录下的 `scripts/read_docx.py`。

**注意：** 如遇扫描件（图片型 PDF），告知用户当前版本暂不支持 OCR，建议提供电子版

读取后先快速浏览全文，识别文件类型（政府采购、工程招标、服务类采购等）和整体结构，再进行提取。

### 第二步：按模板提取信息

按照下方【提取清单】逐项提取。每项内容提取时遵循以下原则：

- **准确引用**：直接摘录原文关键表述，不要改写扭曲含义
- **位置标注**：在括号内注明来源章节（如"第三章"、"附件一"）
- **缺失处理**：若文件未提及某项，标注"文件未载明"而非空白
- **歧义处理**：若某项存在多处矛盾表述，全部列出并加⚠️标记

详细提取规则见 `references/extraction-guide.md`。

### 第三步：生成摘要报告

按 `references/output-template.md` 中的格式输出报告。报告包含两部分：

1. **速览卡片**：项目基本信息 + 最关键的截止日期 + 预算 + 是否有明显限制性条款（3-5 行，供快速判断是否值得深入）
2. **完整解析**：七大维度的结构化内容

报告末尾附一段【投标准备建议】，根据提取内容提示投标方需重点关注的事项（如某证书要求较特殊、某评分项配分较高等）。

### 第四步：上传到飞书（如用户已配置凭证）

生成报告后，检查是否存在飞书凭证（环境变量 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`，或 skill 根目录下的 `.env` 文件）：

- **已配置凭证**：自动调用上传脚本，将报告同步到飞书文档，并返回文档链接
  ```
  python "${CLAUDE_PLUGIN_ROOT}/skills/tender-parser/scripts/feishu_upload.py" <report.md> [--folder-token <文件夹token>]
  ```
- **未配置凭证**：跳过上传，在回复末尾提示用户参考 `references/feishu-setup.md` 完成配置

检查凭证是否已配置：优先检查环境变量，其次检查 `.env` 文件是否存在（用 Glob 查找 `tender-parser/.env`）。凭证检查失败时不要抛出错误，只需在回复末尾友好提示即可。

## 提取清单

提取时，每个维度都有对应的重要性标记：
- 🔴 红线项：不满足则不具备投标资格
- 🟡 关键项：直接影响得分或合规性
- 🟢 普通项：基础信息

### 一、项目基本信息
- 项目名称、项目编号/采购编号
- 采购人/招标人名称
- 采购代理机构（如有）
- 采购类型（货物/服务/工程）
- 项目简要描述/采购内容概述
- 联系人及联系方式

### 二、时间节点
- 招标文件发售时间
- 现场踏勘/答疑时间（如有）
- 投标截止时间 ⚠️（精确到分钟）
- 开标时间和地点
- 投标有效期（自开标日起算的天数）

### 三、资质要求与禁止条款 🔴
这是投标资格判断的核心，需逐条提取：
- 供应商基本资质要求（营业执照类型、经营范围等）
- 注册资本/净资产要求
- 行业资质证书要求（具体证书名称和等级）
- 业绩要求（数量、规模、时间范围）
- 人员资质要求
- 财务状况要求（审计报告、年营业额等）
- 禁止投标情形（信用黑名单、利益冲突等）
- 是否允许联合体投标及条件

### 四、预算与价格要求
- 项目预算金额（最高限价）
- 投标保证金金额、形式、缴纳时间及退还方式
- 履约保证金要求（如有）
- 付款方式和节点
- 合同期限

### 五、评分标准
按评分维度逐项列出，包括：
- 价格分（分值及计算方式）
- 技术分（各子项分值及评分要点）
- 商务分（各子项分值及评分要点）
- 加分项（如有）
- 总分构成示意（如：技术60+商务10+价格30）

### 六、实质性响应条款与承诺要求 🔴
这类条款不满足则直接废标，必须重点标注：
- 明确列出的"实质性响应"要求
- 必须承诺的事项（廉洁承诺、不串标承诺等）
- 需签署/盖章的声明文件清单
- 偏离说明的允许范围（正偏离/负偏离）

### 七、投标文件要求
- 投标文件组成清单（技术标、商务标、资质文件等）
- 封装和密封要求
- 提交方式（现场递交/在线提交）
- 正本副本份数
- 电子版要求（如有）
- 投标文件有效期
